지텔프 문법 가정법 공식과 연습 문제

지텔프 Level 2 · 문법

공식

  • If + 과거(were), 주어 + would/could + 동사원형 (현재 사실 반대)
  • If + had p.p., 주어 + would/could have p.p. (과거 사실 반대)
  • If 생략 도치: Had + 주어 + p.p. / Were + 주어
보기에서 짝이 맞는 조동사 형태를 고르면 돼요.
