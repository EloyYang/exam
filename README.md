# 시험 준비 노트

기출 풀기 · 오답 노트 · 개념 정리로 시험을 준비하는 웹사이트. (처음에는 한국사 지도 노트로 시작했어요)

## 들어 있는 시험

| 시험 | 화면 | 내용 |
| --- | --- | --- |
| 한국사능력검정시험 심화 | `quiz.html` · `review.html` · `history.html` · `typing.html` | 기출 70~80회 풀기, 오답 노트, 시대별 지도 노트, 타자 암기 연습 |
| 지텔프 Level 2 | `gtelp.html` | 문법·독해·청취·필수 단어, 모의고사 10회, 10일 플랜 |
| 소방공무원 공개경쟁·경력경쟁채용 | `fire.html?kind=open` · `?kind=car` | 2022~2026년 필기 기출, 해설, 유형별 개념, 관련 법령 |

## 구조

- `index.html` + `js/home.js` — 시험 선택 화면 (시험별 기록 요약, 시험일 D-day)
- `js/exams.js` — 시험 목록. 새 시험은 여기에 추가
- `js/userstore.js` · `js/auth.js` — 학습 기록 저장 (브라우저 + 구글 로그인 시 Firebase 동기화)
- `js/sub.js` · `PAYMENT.md` — 구독(꺼져 있음), `js/ads.js` · `ADS.md` — 광고(꺼져 있음)

한국사 지도의 경계선은 시험 준비용 개략도입니다.
